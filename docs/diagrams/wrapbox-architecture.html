Wrapbox — Runtime Authorization for AI Agents

Every action an AI agent takes on a managed device is evaluated against one policy, enforced at the operating-system boundary, and recorded as a signed, tamper-evident receipt.

One daemon · Three enforcement points
01
Kernel Floor
macOS Seatbelt confinement
  • File and network denials at the syscall boundary
  • Inherited by every child process the agent spawns
  • The confined process cannot lift its own confinement
  • Symlinks, copies and alternate runtimes are refused alike
02
Policy Ceiling
Agent-native interception
  • PreToolUse interception inside the agent itself
  • Decided from the local signed cache in single-digit milliseconds
  • The decision path never touches the network
  • Fails closed: if the daemon is gone, the action is refused
03
Network Gate
System-wide egress proxy
  • Every browser and application, with no per-app configuration
  • Allow or deny by destination; CONNECT inspected, TLS never intercepted
  • An unattributed process reaching a model API raises its own alarm
  • Loopback and link-local traffic bypass the gate by design
